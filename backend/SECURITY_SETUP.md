# Настройка безопасности Django

## Установленные пакеты

В проект добавлены следующие пакеты безопасности:

1. **django-axes==7.1.0** - Защита от брутфорс-атак на формы входа
2. **django-ratelimit==4.1.0** - Ограничение частоты запросов (rate limiting)

## Что было настроено

### 1. django-axes

**Конфигурация в `settings.py`:**

- Добавлен в `INSTALLED_APPS`
- Добавлен `AxesMiddleware` в `MIDDLEWARE`
- Настроен `AUTHENTICATION_BACKENDS` с `AxesStandaloneBackend`
- Включен `CACHES` с Redis для хранения данных о попытках входа

**Параметры защиты:**
- `AXES_FAILURE_LIMIT = 5` - Максимум 5 неудачных попыток входа
- `AXES_COOLOFF_TIME = 1` - Блокировка на 1 час после превышения лимита
- `AXES_LOCKOUT_PARAMETERS = [['username']]` - Блокировка по имени пользователя
- `AXES_RESET_ON_SUCCESS = True` - Сброс счетчика при успешном входе

**Автоматическая защита:**
django-axes автоматически отслеживает все попытки входа через Django authentication и блокирует пользователей при превышении лимита.

### 2. django-ratelimit

**Конфигурация в `settings.py`:**
- `RATELIMIT_ENABLE = True` - Rate limiting включен
- `RATELIMIT_USE_CACHE = 'default'` - Использует Redis для хранения счетчиков

**Защищенные эндпоинты:**

#### Аутентификация (`apps/users/views.py`):
- **Register**: `5/h` по IP - регистрация ограничена 5 попытками в час
- **Login**: `10/h` по IP - вход ограничен 10 попытками в час

#### Пользовательские действия (`apps/users/views.py`):
- **Follow**: `20/m` по пользователю - подписка ограничена 20 действиями в минуту
- **Unfollow**: `20/m` по пользователю - отписка ограничена 20 действиями в минуту
- **Search**: `30/m` по IP - поиск ограничен 30 запросами в минуту

#### Посты (`apps/posts/views.py`):
- **Create Post**: `10/m` по пользователю - создание постов ограничено 10 в минуту
- **Like/Unlike**: `30/m` по пользователю - лайки/анлайки ограничены 30 действиями в минуту

## Требования для работы

1. **Redis** должен быть запущен и доступен по адресу из переменных окружения:
   - `REDIS_HOST` (по умолчанию: localhost)
   - `REDIS_PORT` (по умолчанию: 6379)

2. **PostgreSQL** должен быть запущен для работы миграций django-axes

## Установка и миграции

### 1. Установите зависимости:

```bash
cd backend
pip install -r requirements.txt
```

### 2. Примените миграции для django-axes:

```bash
python manage.py migrate
```

Эта команда создаст таблицы в базе данных для хранения информации о неудачных попытках входа.

### 3. Проверьте, что Redis запущен:

```bash
redis-cli ping
# Должно вернуть: PONG
```

## Проверка работы

### Проверка django-axes:

1. Попробуйте войти с неверным паролем 5 раз
2. На 6-й попытке вы должны получить блокировку на 1 час
3. Проверить заблокированных пользователей можно в админ-панели Django: `/admin/axes/`

### Проверка django-ratelimit:

1. Попробуйте зарегистрироваться более 5 раз в час - получите ошибку 429
2. Попробуйте создать более 10 постов в минуту - получите ошибку 429
3. При превышении лимита сервер вернет HTTP 403 Forbidden

## Настройка лимитов

Вы можете изменить лимиты в соответствующих файлах:

### В `settings.py` для django-axes:
```python
AXES_FAILURE_LIMIT = 5  # Измените количество попыток
AXES_COOLOFF_TIME = 1   # Измените время блокировки (в часах)
```

### В `views.py` для django-ratelimit:
```python
@method_decorator(ratelimit(key='ip', rate='5/h', method='POST'))
                                          # ^ Измените: 'количество/период'
                                          # Период: s (секунды), m (минуты), h (часы), d (дни)
```

## Мониторинг

### Просмотр заблокированных IP/пользователей:

```bash
python manage.py axes_list_attempts
```

### Разблокировка пользователя:

```bash
python manage.py axes_reset username
```

### Разблокировка IP:

```bash
python manage.py axes_reset_ip <ip_address>
```
